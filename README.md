## 电视适配

- 大纲首页采用左右固定侧栏与居中图片网格，移除顶部搜索栏和底部导航，统一图标、间距与焦点样式。
- 左栏提供搜索、已存搜索、筛选和收藏；右栏显示页码、上一页/下一页、应用菜单和帮助。
- 网格左右边缘进入对应侧栏，侧栏向内返回原图片；上下限保持网格焦点，选中框不越出可见区域。
- 大纲页禁用左右滑动翻页，改用右栏可选中的翻页按钮，避免方向导航误翻页。
- 独立全屏搜索，自动打开系统键盘；收起键盘后可以逐条选择标签和历史联想。
- 左图右详情，媒体、标签与操作按钮使用明确的遥控焦点路径。
- 全屏预览隔离背景详情，避免残留选中框；操作栏使用固定图标焦点。
- 视频播放、暂停、快退、快进、声音及全屏切换使用电视操作栏。
- 支持电视账号密码登录、API 密钥登录，以及同局域网手机扫码登录。
- 新增电视界面支持简体中文、繁体中文、英文和日文，默认跟随系统语言；扫码网页使用电视当前语言。
- 移除顶部空广告容器占位；保留原应用的网络、收藏、筛选和媒体解码逻辑。

## 遥控操作

| 场景 | 操作 |
| --- | --- |
| 首页 | 方向键移动，确定打开，长按确定打开原有操作 |
| 网格边缘 | 左右进入对应侧栏，向内返回原图片；上下限停留在网格 |
| 左侧栏 | 搜索、已存搜索、筛选、收藏；搜索确定进入全屏搜索并打开键盘 |
| 右侧栏 | 上下选择上一页/下一页、应用菜单和帮助，确定执行；页码固定显示 |
| 全屏搜索 | 返回先收起键盘，下进入联想，上下选择，确定搜索；再返回取消 |
| 详情媒体 | 左右上一张/下一张，上进入详情，下进入操作栏，确定全屏 |
| 详情标签 | 上下浏览，左返回媒体，到末项下进入操作栏 |
| 全屏图片 | 左右翻图，下打开操作栏，上收起，返回退出全屏 |
| 全屏视频 | 确定播放/暂停，画面上左右快退/快进，下打开播放栏 |
| 全屏操作栏 | 左右选择图标，确定执行，上收起 |
| 返回 | 先退出全屏，再返回列表 |
| 菜单键 | 打开电视快捷菜单 |

安装包 SHA256：


## 构建

此项目是固定 APK 版本的补丁工程，**不是 Gradle/Android Studio 源码工程**。
原版更新后，补丁的资源与方法签名可能改变，不能直接套用。

### 环境

- Windows / PowerShell 7，JDK 17 或更新版本。
- Android SDK：Platform 35、Build Tools 37.0.0。
- Python 3 与 Pillow：`python -m pip install Pillow`。
- 从原作者官方页面取得所需基线 APK，命名为 `original.apk` 放在仓库根目录。
- 在 `tools/` 准备以下依赖，文件名需要一致：

| 文件 | 版本 / 来源 |
| --- | --- |
| `apktool.jar` | 3.0.3，[Apktool 官方](https://apktool.org/) |
| `zxing-core-3.5.3.jar` | 3.5.3，[ZXing 官方项目](https://github.com/zxing/zxing) |
| `jsoup-1.18.3.jar` | 1.18.3，[jsoup 官方](https://jsoup.org/) |
| `jsencrypt-3.3.2.min.js` | 3.3.2，[JSEncrypt 官方项目](https://github.com/travist/jsencrypt) |

设置本机环境及自己的签名口令，然后构建：

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk'
$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"
# 使用自己的签名口令，勿将真实口令提交到仓库。
$env:TWS_TV_KEYSTORE_PASSWORD = '<your-local-signing-password>'
.\build.ps1
# 仅在原 APK 与补丁未改变、已完整构建过时使用：
.\build.ps1 -SkipDecode
```

工具位置也可以用 `-JavaHome`、`-Sdk`、`-Python`、`-Stage` 参数指定。
构建阶段保留原 APK 的 DEX、资源和网络逻辑，新增 `classes3.dex`。
`patch.py` 在修改前校验固定基线的关键方法签名，签名不符会停止。

## 登录与安全

手机与电视连接同一可信局域网，在登录页选择“手机扫码”，扫描后完成登录。
也可直接在电视输入用户名和密码，或使用 API 密钥。

- 手机提交的凭据使用临时 RSA 公钥加密；电视访问网站使用 HTTPS。
- 手机登录页面是局域网 HTTP，不保证抵御主动中间人攻击，请勿在不可信网络使用。
- 扫码地址随机且十分钟过期；取消、退出或登录成功后关闭临时服务。
- 密码不持久化；原应用按需保存用户名与 API 密钥。
- 优先复用有效 API 密钥；没有有效密钥时可能创建 TWS-TV 专用密钥。
- 网站要求浏览器验证或启用两步验证时，使用 API 密钥方式。

## 语言

电视适配层的搜索、快捷栏、帮助、播放按钮、登录提示和扫码网页提供四种完整翻译。
原应用已有的其他语言资源继续保留；未新增翻译的电视文字回退为英文。
这不代表原应用所有页面均已补齐繁体中文或日文。

首次升级到 tv5 会清除旧版的固定语言设置，改为“跟随系统”。
之后可在原应用语言设置中选择“跟随系统”或手动指定语言；后续启动不会重复清除选择。
Android 13 及以上也提供应用语言列表，尚未在 Android 13 电视上实测。

翻译统一维护在 [locales/strings.json](locales/strings.json)，说明见 [locales/README.md](locales/README.md)。
修改资源后必须完整构建，不能使用 `-SkipDecode`。
运行 `python -m unittest discover -s tests` 可检查翻译和格式占位符。
