# TV translations

`strings.json` is the source of the Android string resources generated by `patch.py`.
Every resource has four translations in this order: simplified Chinese, English,
traditional Chinese, Japanese. English is the default fallback.

Keep resource keys stable and keep format placeholders identical in every language.
Android selects resources from the current configuration. No locale is cached in Java.
The phone login page uses the TV's current language and the same translations.

Run `python -m unittest discover -s tests` before building.
New resource translations require a full build; `-SkipDecode` cannot update resources.
